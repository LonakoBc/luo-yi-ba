# 洛一把

一个收录洛天依与乐正绫传说曲的网页音乐小游戏，目前包含“猜歌”“曲名填字”和歌曲数据库。两个歌姬曲库合并去重后共有 239 首作品。

- **猜歌**：根据 STAFF、发布时间、演唱歌姬、声库等反馈逐步锁定答案。
- **曲名填字**：将六首纯汉字曲名横纵交叉排列，依据两个固定首字与可选歌词提示逐格完成曲名。

## 曲库范围

- **自定义曲库**：按歌姬、声库、特殊标注、发布时间和演唱会／生日会经历筛选。
- **挑战全曲库！**：一次挑战当前收录的全部 239 首不同作品。
- **洛天依入门曲库**：50 首热门及较为出圈的洛天依精选作品。
- **洛天依传说曲**：人工审核后的 219 首完整曲库。
- **乐正绫传说曲**：人工审核后的 51 首完整曲库。
- **黄金时代**：收录全部歌姬在 2015—2019 年发布的 102 首不同作品。

## 本地运行

请先安装 Node.js 22，然后执行：

```bash
cd web
npm install
npm run dev
```

生产构建：

```bash
cd web
npm run build
```

## 项目结构

```text
singers/              歌姬采集与发布配置
database/singers/     人工审核后的歌姬 JSON 数据源
song/song_<id>/       由审核 JSON 生成的歌曲 Markdown
presets/              Markdown 曲库预设
scripts/              数据采集与题库生成脚本
web/                  React + Vite 网页应用
bgm/                  网站背景音乐
test/                 数据脚本测试
```
