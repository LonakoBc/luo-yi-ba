# 「洛一把」多人联机开发日志

## 项目背景

「洛一把」是一个以中文虚拟歌手歌曲资料为基础的网页小游戏合集，包含曲目猜猜看、谁是老资历、歌曲大排序等玩法。项目最初只有本地单机状态，后续才加入房间码、WebSocket 实时同步和服务端权威判定。

多人版本的目标一直比较克制：不做大厅、匹配、聊天、账号和旁观，只实现创建房间、分享六位房间码、2–4 人加入并完成一场比赛。正是这个约束，让我们能把主要精力放在玩法、公平性、断线恢复和跨平台发布上。
